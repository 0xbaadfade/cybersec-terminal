CYBERSEC TERMINAL (web version)

This folder is the game as a web page. Put all of these files together on any web server and open index.html
through it. It will NOT work if you double-click index.html (browsers block that); to try it on your own computer:

  python3 -m http.server 8765        (run inside this folder)
  then open  http://localhost:8765/index.html

Progress is saved in the browser, on that computer, per site address.
